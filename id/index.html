Sebelum mengunduh

Apakah Mindrink gratis?
Ya. Tidak ada langganan atau iklan.
Apakah saya perlu membuat akun?
Tidak. Kamu dapat mulai mencatat tanpa mendaftar.
Apakah saya harus sedang berusaha berhenti minum?
Tidak. Kamu cukup membuat catatan dan memahami polamu.
Di mana catatan minum saya disimpan?
Catatan minummu tetap berada di perangkatmu. Peristiwa analitik tidak mencakup jenis atau jumlah minuman yang kamu masukkan. Analitik penggunaan diaktifkan secara default dan menggunakan ID yang dibuat oleh aplikasi, bukan namamu. Di iOS, analitik ini dapat mencakup rekaman interaksi di layar; komponen teks standar dan kolom input disamarkan. Kamu dapat menonaktifkan analitik di Pengaturan. Laporan kesalahan teknis dikumpulkan secara terpisah dan tidak dinonaktifkan oleh pengaturan tersebut.Detail privasi

Alasan Mindrink hadir

Mindrink membantu kamu memahami pola minummu tanpa menjadikan berhenti minum sebagai tujuan.

Mengakses dan mengekspor catatan minummu sendiri seharusnya tidak memerlukan langganan.
