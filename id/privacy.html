Kebijakan Privasi

Terakhir diperbarui: 29 Agustus 2026

Kebijakan privasi ini menjelaskan bagaimana Mindrink menangani informasi di aplikasi seluler dan situs publik mindrink.me. Situs tidak memakai cookie iklan atau analitik. Analitik situs dengan data minimal dijelaskan di bawah dan dapat dimatikan kapan saja.

Kontak privasi: hello@mindrink.me

Siapa kami

Mindrink adalah proyek independen dan nonkomersial. Ini bukan produk perusahaan, dan tidak didanai dari penjualan data pengguna.

Aplikasi ini tidak memakai akun. Riwayat minum tidak disimpan di server Mindrink.

Informasi yang hanya disimpan di perangkat kamu

Hal berikut disimpan secara lokal di perangkat kamu dan tidak diunggah ke server Mindrink:

  • catatan minuman, hari tanpa alkohol, refleksi, dan tujuan
  • pengaturan, termasuk batas dan profil panduan
  • file cadangan atau ekspor yang kamu buat

Mindrink tidak dapat mengakses informasi ini. Jika kamu mengekspor atau mencadangkan file, kamu yang memilih lokasi penyimpanannya. Mindrink tidak menerima file itu.

Jika kamu mengaktifkan pengingat, aplikasi memakai izin notifikasi perangkat. Isi pengingat tetap di perangkat.

Informasi yang kami kumpulkan

Analitik. Analitik aktif secara default dan dapat dimatikan di Pengelolaan Data. Selama aktif, kami mengirim data penggunaan anonim ke Amplitude (Uni Eropa). Ini dapat mencakup versi aplikasi, kelas perangkat, sistem operasi, ukuran layar, negara dari pengaturan lokal perangkat, bahasa, tema, apakah pengingat aktif, dan profil panduan yang kamu pilih. Tidak mencakup riwayat minum, refleksi, catatan, atau tujuan. Kami tidak mengumpulkan pengenal iklan atau alamat IP untuk analitik.

Analitik situs. Mindrink mengirim sejumlah kecil peristiwa agregat yang ditentukan secara eksplisit ke PostHog Cloud EU: halaman dilihat, klik ke halaman lain di mindrink.me, dan empat tindakan kalkulator. Peristiwa hanya boleh menyertakan bahasa, jalur halaman yang dinormalisasi, jenis kalkulator, dan lokasi CTA bila relevan. Teks tautan, perujuk, input minuman, volume, ABV, jumlah, hasil, total, informasi kesehatan, teks bebas, parameter kueri, dan URL lengkap tidak pernah dikirim. PostHog hanya memakai pengenal sementara di memori halaman; tidak ada pengenal yang bertahan ke halaman berikutnya, sehingga perjalanan lengkap tidak ditautkan ke seseorang. Autocapture, profil, rekaman sesi, heatmap, pengukuran performa, pengayaan GeoIP, dan penyimpanan PostHog persisten dinonaktifkan. Global Privacy Control dan Do Not Track dihormati secara otomatis. Hanya pilihan opt-out yang disimpan jika kamu mematikan analitik di bawah.

Laporan crash dan error. Kami mengirim laporan teknis crash dan error ke Sentry untuk mendiagnosis kegagalan. Laporan ini dapat mencakup stack trace dan metadata diagnostik. Laporan dikonfigurasi agar tidak mencakup riwayat minum, tangkapan layar, atau pengenal pribadi default.

Komunikasi dukungan. Jika kamu mengirim email atau masukan lewat Tally, kami menerima isi yang kamu kirim.

Kami tidak menjual informasi pribadi. Kami tidak memakai data untuk iklan.

Bagaimana kami memakai informasi

  • Data lokal aplikasi hanya dipakai di perangkat kamu untuk menjalankan aplikasi.
  • Analitik dipakai untuk memahami penggunaan secara agregat dan memperbaiki Mindrink.
  • Laporan crash dipakai untuk memperbaiki bug dan menjaga keandalan.
  • Pesan dukungan dipakai untuk membalas kamu.

Berbagi

Kami hanya membagikan informasi kepada penyedia layanan yang memprosesnya atas nama kami:

  • Amplitude, untuk analitik opsional (UE)
  • PostHog Cloud EU, untuk analitik situs dengan data minimal
  • Sentry, untuk diagnosis crash dan error
  • Tally, untuk masukan yang kamu pilih untuk dikirim

Kami tidak membagikan riwayat minum kepada siapa pun, karena kami tidak menerimanya.

Retensi data

  • Catatan minuman, refleksi, tujuan, dan pengaturan lokal. Mindrink tidak menyimpan atau menahan data ini di server kami. Data itu hanya ditahan di perangkat kamu sampai kamu menghapusnya di aplikasi atau mencopot pemasangan aplikasi.
  • Analitik. Amplitude menahan peristiwa penggunaan anonim selama diperlukan untuk menganalisis penggunaan dan memperbaiki aplikasi, lalu menghapusnya sesuai pengaturan retensi Amplitude. Mematikan analitik menghentikan pengumpulan baru.
  • Analitik situs. Peristiwa situs di PostHog disimpan paling lama 90 hari. Mematikannya menghentikan pengumpulan baru di browser ini.
  • Laporan crash dan error. Sentry menahan laporan diagnostik untuk jangka waktu terbatas yang diperlukan guna menyelidiki dan memperbaiki masalah, lalu menghapusnya sesuai pengaturan retensi Sentry.
  • Email dan masukan. Kami menahan komunikasi ini selama diperlukan untuk menangani permintaanmu, lalu menghapusnya ketika tidak lagi dibutuhkan.

Karena analitik dan laporan crash tidak terikat ke akun atau pengenal pengunjung persisten, kami tidak dapat mengidentifikasi atau menghapus data Amplitude, PostHog, atau Sentry milik orang tertentu.

Penghapusan

Aplikasi ini tidak membuat akun Mindrink.

Kamu dapat menghapus data lokal aplikasi kapan saja di Pengelolaan Data. Mencopot pemasangan aplikasi juga menghapus data lokal di perangkat itu.

Untuk meminta penghapusan email atau masukan yang kamu kirim, hubungi hello@mindrink.me.

Kami tidak dapat menghapus data Amplitude, PostHog, atau Sentry milik orang tertentu. Data itu tidak terikat ke akun atau pengenal pengunjung persisten.

Keamanan

Data minum lokal disimpan di perangkat. Cadangan Android untuk aplikasi dimatikan, jadi mencopot pemasangan menghapus data lokal itu. Analitik dan pelaporan crash dikonfigurasi untuk mengecualikan riwayat minum dan membatasi pengenal. Analitik Amplitude dikirim ke endpoint UE Amplitude, tanpa alamat IP atau pengenal iklan. Analitik situs dikirim ke endpoint UE PostHog dengan penyimpanan IP dan pengayaan GeoIP dinonaktifkan; koneksi jaringan tetap secara teknis memperlihatkan IP permintaan kepada PostHog saat tiba.

Anak-anak

Mindrink ditujukan bagi orang yang sudah mencapai usia legal minum di negara tempat mereka tinggal. Aplikasi ini tidak ditujukan kepada anak-anak.

Perubahan
